## About

This project contains my Week 6 internship task on creating a Cybersecurity Audit Plan for a hypothetical organization.

The objective of this task is to establish a structured approach for regularly reviewing cybersecurity practices, identifying security gaps, evaluating controls, and tracking improvements.

## Audit Areas Covered

* Cybersecurity Governance
* Access Control
* Authentication and MFA
* Network Security
* Endpoint Security
* Vulnerability Management
* Application Security
* Database Security
* Data Protection
* Cloud Security
* Incident Response
* Backup and Disaster Recovery
* Security Awareness
* Third-Party Security
* Physical Security
* Security Monitoring and Logging

## Key Features

* Risk-Based Audit Approach
* Audit Methodology
* Evidence Collection
* Audit Schedule
* Annual Audit Cycle
* Roles and Responsibilities
* Finding Classification
* Remediation Tracking
* Follow-Up Audits
* Audit Metrics
* Continuous Improvement
